# CLAUDE.md - AI Assistant Guide for UKRS2

## Project Overview

**UK Railway Set (UKRS2) - Community Bugfixes** is an OpenTTD NewGRF (Graphics Replacement File) providing British railway vehicles for the transport simulation game OpenTTD/TTDPatch.

- **Original Author**: David Dallaston (PikkaBird)
- **Bugfix Maintainer**: Mircea Chirea
- **Repository**: https://github.com/CMircea/UKRS2
- **Current Version**: 1.06
- **GRF ID**: `MCX` (prefix for both sets)

## File Formats

### NFO Files (`.nfo`)
- **Low-level NewGRF source format** - assembly-like syntax
- Generated by decompiling GRF files using GRFCodec
- Contains sprite definitions, action blocks, and vehicle properties
- Line format: `spritenum * size [data]`

### GRF Files (`.grf`)
- **Compiled binary format** for OpenTTD/TTDPatch
- Created from NFO files using grfcodec
- Users install these files in their OpenTTD `newgrf` directory

## Development Workflow

### Required Tools
- **GRFCodec**: Compiles NFO to GRF and decompiles GRF to NFO
- **NFORenum**: Validates and formats NFO files (fixes sprite numbers, checks syntax)

Install on Debian/Ubuntu:
```bash
apt-get install grfcodec
```

### Build Commands

**Compile NFO to GRF:**
```bash
grfcodec -e ukrs2.grf
grfcodec -e ukrs2-addon.grf
```

**Decompile GRF to NFO:**
```bash
grfcodec -d ukrs2.grf
grfcodec -d ukrs2-addon.grf
```

**Validate/format NFO files:**
```bash
nforenum ukrs2.nfo
nforenum ukrs2-addon.nfo
```

### Typical Edit Workflow
1. Edit the `.nfo` file(s)
2. Run `nforenum` to validate and fix sprite numbers
3. Run `grfcodec -e` to compile
4. Test in OpenTTD
5. Commit both `.nfo` and `.grf` files

## NFO Code Structure

### Key Action Types
- **Action 0**: Define vehicle properties (speed, power, cost, etc.)
- **Action 1**: Define sprite sets (graphics)
- **Action 2**: Define sprite groups and VarAction2 (computed graphics/callbacks)
- **Action 3**: Assign graphics to vehicles
- **Action 4**: Define text strings
- **Action 7/9**: Conditional skips (version checks, parameter checks)
- **Action 8**: GRF metadata (ID, name, description)
- **Action 14**: Extended GRF info (parameters, URL, etc.)

### VarAction2 (Variable Action 2)
Used for computed decisions based on game state:
- Railtype checks (standard, electrified, 3rd rail)
- Livery variations
- Callback results

### Rail Types
The set supports multiple rail types with specific labels:
- Standard rail: `RAIL`
- Electrified (overhead): `ELRL`
- Third rail: `3RDR`, `3RDC` (with catenary)
- Various speed-class variants

## Configuration Parameters

The main GRF includes user-configurable parameters:
1. **Locomotive Selection**: No/Small/TT Style/Normal/Extended
2. **Wagon Selection**: No/TT Style/Normal/Extended
3. **Single Livery**: Use one livery variation
4. **Real Colours**: Real-world colors vs company colors
5. **Real Coloured Containers**: Container color option
6. **Enable Identifier Flags**: Show UK flags in buy menu
7. **Disable Running Sounds**: Mute train sounds
8. **De-clutter Purchase list**: Remove old locos faster

## Key Technical Notes

### GRF Dependencies
- `ukrs2-addon.grf` requires `ukrs2.grf` to be loaded first
- Both require OpenTTD 1.2.0 or later
- May conflict with other train sets

### Common Bug Areas
Based on commit history, focus areas include:
- **Railtype VarAction2 chains**: Ensuring correct indexes for catenary/3rd rail checks
- **Rail table definitions**: Speed classes and rail type compatibility
- **GRF ID consistency**: Must match across compatible wagon checks

### Version String Location
In `ukrs2.nfo` around line 80-88 (Action 8):
```
"UK Railway Set (UKRS2) - Community Bugfixes" 00
94 "Version " 95 "1.06"
```

## Conventions for AI Assistants

### DO
- Run `nforenum` after editing NFO files to validate syntax
- Commit both `.nfo` and `.grf` files together
- Update version numbers in both NFO files when releasing
- Test GRF files in OpenTTD after changes
- Keep changes minimal and focused on bugfixes

### DON'T
- Modify the GRF files directly (always edit NFO source)
- Change the GRF ID without coordination
- Add new vehicles (out of scope for bugfix repository)
- Ignore nforenum warnings (fix them or understand why they're acceptable)

### Commit Message Style
Based on history, use imperative mood describing the fix:
```
Fix dual 3rd rail & catenary trains not running at full speed/power under catenary.
Update VarAction2 with correct railtype indexes for overhead catenary
Run nforenum.
```

## Testing

1. Copy compiled `.grf` files to OpenTTD's `newgrf` directory
2. Enable in OpenTTD's NewGRF settings
3. Start a new game in the UK
4. Verify trains appear correctly and function as expected
5. Test specific fixes (e.g., railtype compatibility, speeds, powers)
